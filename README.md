# CS_320_Artifact

# How can I ensure that my code, program, or software is functional and secure?

We can ensure that our software works correctly and remains secure by following good coding practices and testing throughout development. By testing as we build and performing thorough tests at the end, we can catch errors early and verify that each part behaves as expected. Using unit tests and checking edge cases helps prevent defects, and by writing secure code and running tests specifically for security, we can reduce vulnerabilities and keep the software reliable for users.

# How do I interpret user needs and incorporate them into a program?

We can interpret user needs by carefully reading and analyzing project requirements. Each requirement can be broken down into clear tasks, which we implement in the program and verify with tests. For this project, my main strategy was to translate each requirement into one or more JUnit tests, so every rule could be checked automatically. This approach ensures that the software meets user expectations and behaves as intended.

# How do I approach designing software?

We can approach software design systematically by following the software development life cycle (SDLC) and focusing on clear, organized, and maintainable code. Following discipline, consistency, good coding syntax rules, and adhering to best practices throughout development is very helpful. We can plan components with specific responsibilities and design alongside the right tests. By keeping security practices in mind and integrating tests throughout development, we can catch issues early and maintain reliability. This structured approach helps ensure that the program remains functional, secure, and easy to maintain as it evolves.
